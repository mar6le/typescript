# TypeScript Проєкт

Цей репозиторій містить базовий TypeScript проєкт з налаштуваннями для розробки.

## Опис

Проєкт налаштований для роботи з TypeScript, включає базову конфігурацію компілятора та приклади використання основних типів даних.

## Структура проєкту

- `src/` - вихідний код TypeScript
- `dist/` - скомпільований JavaScript код
- `tsconfig.json` - конфігурація TypeScript компілятора

## Встановлення

```bash
npm install
```

## Компіляція

```bash
npm run build
```
