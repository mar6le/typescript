# TypeScript Interactive Template

Цей проєкт демонструє використання TypeScript для створення інтерактивних веб-додатків з модальними вікнами, анімаціями та інтеграцією з API.

## Опис

Проєкт включає:

- Сучасний HTML/CSS шаблон з адаптивним дизайном
- TypeScript код з повною типізацією
- Інтерактивні елементи (модальні вікна, анімації, API запити)
- Інтеграцію з JSONPlaceholder API

## Структура проєкту

- `src/app.ts` - основний TypeScript файл з усією інтерактивністю
- `index.html` - HTML шаблон
- `styles.css` - стилі CSS
- `dist/app.js` - скомпільований JavaScript файл
- `tsconfig.json` - конфігурація TypeScript

## Встановлення

```bash
npm install
```

## Компіляція

```bash
npm run build
```

## Запуск

Відкрийте `index.html` у браузері або використайте локальний сервер:

```bash
npx serve .
```

## Інтерактивність

### 1. Модальне вікно

- Відкриття модального вікна при кліку на кнопку "Відкрити модальне вікно"
- Закриття через кнопку X, клік поза вікном або клавішу Escape
- Блокування скролу сторінки під час відкриття модального вікна

### 2. Анімації при скролі

- Плавне з'явлення секцій при прокрутці сторінки
- Анімація появи карток постів з затримкою
- Зміна тіні header при скролі

### 3. Event Listeners

- **Click events**: клік на картки постів, кнопки, модальне вікно
- **Scroll events**: анімації при скролі, зміна стилю header
- **Mouse events**: hover ефекти на картках постів
- **Keyboard events**: закриття модального вікна через Escape

### 4. Fetch API

- Завантаження постів з JSONPlaceholder API
- Відображення спіннера під час завантаження
- Обробка помилок при невдалому запиті
- Відображення перших 9 постів у вигляді карток

### 5. Плавна навігація

- Плавний скрол до секцій при кліку на посилання в навігації
- Врахування висоти header при скролі
